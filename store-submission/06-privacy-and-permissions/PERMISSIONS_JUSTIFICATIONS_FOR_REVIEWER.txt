1. Single Purpose Description (单一用途说明):
--------------------------------------------------------------------------------
Automates MCP (Model Context Protocol) tool permission approvals, continuation confirmation chips, per-conversation controls with isolated emergency stops, background/minimized/sleep continuation, and stall auto-recovery exclusively on the Google Gemini web application.


2. Host Permissions Justification (主机权限说明 - https://gemini.google.com/*):
--------------------------------------------------------------------------------
The extension exclusively interacts with Google Gemini (https://gemini.google.com/*) to detect MCP approval dialogs, click confirmation chips, enforce per-conversation toggles and isolated emergency stops, maintain background/minimized continuation, and render an on-page draggable status HUD. The extension requests no access to any other website or domain.


3. Permission: storage (存储权限):
--------------------------------------------------------------------------------
Required to persist global user preferences (cooldown intervals, breaker thresholds, HUD position coordinates, theme/language, and custom keyword lists), daily local click counters, and per-conversation override settings / isolated emergency-stop flags (gmah_chat_overrides_v1) locally on the device via chrome.storage.local.


4. Permission: tabs (标签页权限):
--------------------------------------------------------------------------------
Required to identify active Google Gemini tabs and their conversation path for per-chat control matching in the popup and background service worker, toggle autoDiscardable per active background-enabled Gemini tab to prevent premature tab discarding, and bring the corresponding Gemini tab into focus when the user clicks a desktop stall or circuit-breaker alert.


5. Permission: alarms (定时器/闹钟权限):
--------------------------------------------------------------------------------
Required to maintain periodic keepalive heartbeats, minimized-window follow-up wakeups, and post-sleep/background continuation ticks in the Manifest V3 service worker so that automated background tasks do not stall or terminate prematurely when the browser window is minimized, inactive, or waking from sleep.


6. Permission: scripting (脚本注入权限):
--------------------------------------------------------------------------------
Required to (1) dynamically inject bundled content scripts into already-opened https://gemini.google.com/* tabs upon extension install or update without requiring a browser restart, and (2) execute a strictly local, self-contained world: "MAIN" helper (mainWorldClickByToken and a lightweight renderer wake ping) exclusively on Gemini tabs when background, minimized, or unfocused tab throttling affects isolated-world clicks on Shadow DOM or Angular Material confirmation chips. No remote code is fetched or executed, and no arbitrary page data is extracted.


7. Permission: notifications (桌面通知权限):
--------------------------------------------------------------------------------
Required solely to display native desktop alert notifications when an MCP tool execution or Gemini text generation hangs/stalls longer than the user-configured timeout threshold (default 5 minutes) or when a safety circuit breaker trips, allowing the user to click the alert and jump straight back to the corresponding Gemini tab.


8. Remote Code Execution Declaration (远程代码执行声明):
--------------------------------------------------------------------------------
The extension does NOT use or execute any remote code. All JavaScript files, CSS stylesheets, and HTML documents (including the local MAIN-world click helper function) are fully bundled locally within the extension zip package, in strict compliance with Chrome Web Store Manifest V3 security guidelines.
