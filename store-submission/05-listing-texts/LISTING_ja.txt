Gemini の MCP 権限許可・続行を自動クリック。4言語対応、ライト/ダークモード、左押下ドラッグ HUD、誤爆防止＆回路遮断器を内蔵。

============================================================
3. 詳細な説明 (Detailed Description - 下記内容をそのまま貼り付け)
============================================================
KenEasy Gemini MCP Auto Helper は、Google Gemini ウェブ版（gemini.google.com）向けに設計された MCP ツール自動承認および連続チャット支援拡張機能です。

ローカルやリモートの MCP サーバーを呼び出す際、「常に許可」や「続行」を何度も手動でクリックする必要がなくなります。v0.3 Beta では 4言語対応、ライト/ダークテーマ切替、ホバー誤追従を修正したドラッグ HUD、複数ブラウザ・非チャット画面での誤クリック防止ガードを搭載しました。

🌟 主な機能 (V0.3 Beta)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ 1. インテリジェントな MCP 権限承認＆誤操作ガード
• 「常に許可（Always allow）」ボタンを自動認識してスマートに承認。
• Material Web Components の Shadow DOM、<slot>、ドロップダウンメニューに対応。
• `/gems` や `/settings` 等のチャット外ページ、回答0件のホーム画面、2つ目のブラウザ復元タブの古いチップによる誤クリックを防止。
• 厳格なブラックリスト機能：拒否・キャンセル・削除などのボタンは絶対に誤クリックしません。

🖱️ 2. 左ボタン押下ドラッグ可能な HUD パネル 🆕
• 左クリックでヘッダーを押下したままの時だけ移動（ホバーしただけでは追従しません）。
• 4px 閾値後にポインターキャプチャを行い、折りたたみ・テーマ・言語ボタンが確実に反応。位置リセットにも対応。

🌗 3. 4言語切替 + ライト/ダークテーマ対応 🆕
• 簡体字中国語 / 繁体字中国語 / English / 日本語 をワンクリック切替（通知・キーワード対応）。
• ダークモード（🌙）とライトモード（☀️）を HUD とポップアップ間でリアルタイム同期。

🔔 3. タイムアウト時のデスクトップ通知・ワンクリック切替 🆕
• ツールの停止や生成が一定時間（デフォルト5分）停滞した場合、ネイティブ通知でお知らせ。
• HUD パネルおよびポップアップからワンクリックで通知のオン/オフを切替可能。
• 通知をクリックすると、該当の Gemini タブへ瞬時に移動して最前面化。

🤖 4. 自動「続行」および「Yes」チップの自動クリック
• 回答末尾の「↪ Yes」や「続行（Continue）」ボタンを自動的に認識してクリック。
• アンケートやナビゲーションは除外するため安全です。

🛡️ 5. 6層の回路遮断器（安全保護機能）
• レイヤー 1：レートリミットや上限エラーを検知して瞬時に自動停止。
• レイヤー 2：1回のタスクあたりの連続クリック上限（デフォルト10回）。
• レイヤー 3：テキスト出力が安定するまで待機（1.8秒）＋クールダウン（4秒）。
• レイヤー 4：1日あたりの最大クリック上限管理。
• レイヤー 5：「完了しました」などの終了文言を認識して無駄なクリックをスキップ。
• レイヤー 6：同一出力の繰り返しや進展がない場合に自動停止。
