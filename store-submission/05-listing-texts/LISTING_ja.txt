3. 詳細な説明 (Detailed Description - 下記内容をそのまま貼り付け)
============================================================
KenEasy Gemini MCP Auto Helper は、Google Gemini ウェブ版（gemini.google.com）向けに設計された MCP ツール自動承認および連続チャット支援拡張機能です。

ローカルやリモートの MCP サーバーを呼び出す際、「常に許可」や「続行」を何度も手動でクリックする必要がなくなります。v2.2 では**既定モデル固定とレスポンシブ自動切替ガード**（モデル変化時に自動復帰、利用不可・反復復帰失敗時は即エラー停止）を新搭載し、Notion 風ミニマル UI、チャット単位制御、バックグラウンド・最小化・スリープ復帰継続、自動再接続と 6 層回路遮断器を統合しました。

🌟 主な機能 (V2.2)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 0. 既定モデル固定＆レスポンシブ自動切替ガード 🆕
• HUD やポップアップから既定の作業モデル（プリセット・自由入力・現在モデル取得・一覧検出）を全体またはチャット単位で設定可能。待機時・続行前・停滞自動再開前に自動検証し、ずれていれば自動復帰します（生成中は邪魔しません）。
• デスクトップ `<header>`・入力欄バー・Shadow DOM・狭い画面のボトムシート・高ズーム（`visualViewport` 追従＆HUD スクロール）・バックグラウンド/最小化タブ（二重トグル防止）すべてに対応。
• 対象モデルが上限/ロック・未検出・エラー表示・反復リセットされる場合は `model_unavailable` で即時停止し、赤色 `ERR` バッジとデスクトップ通知でお知らせします。

🛌 1. バックグラウンド・最小化・消灯/スリープ復帰時の継続強化
• バックグラウンド・最小化・非フォーカス状態の判定を強化し、「常に許可」および「続行」チップの初回クリックでもバックグラウンド/最小化時に `MAIN` ワールドクリックへ昇格して ShadowRoot や Material チップを貫通し、クリック漏れを抑えます。
• 非表示・消灯・スリープ状態からの復帰時に共有 Web ロックの再取得、ポート再接続、即時スキャンを実行し、チャット単位の `autoDiscardable` 保護や最小化 `1200ms` フォローアップウェイクアップと連携します。

🎛️ 2. チャット単位の独立制御＆隔離緊急停止
• HUD の「本チャット / グローバル」切替やポップアップ上部の「現在のチャット独立制御」カードから、6 つの主要スイッチ（全体有効、常に許可自動クリック、続行自動クリック、バックグラウンド動作、タイムアウト通知、タイムアウト自動再接続）をチャットごとに独立設定でき、グローバルと異なる項目は自動表示されます。
• 緊急停止は現在のチャットのみをロックしてルート遷移後も保持し、他のチャットやタブはそのまま動作します。グローバル停止用の「全チャット停止」ボタンもポップアップ下部に用意しています。
• `/app` 画面の個別設定は新規作成された `/app/<id>` セッションへ自動移行し、ワンクリックでグローバル既定へ戻せます。

⏱️ 3. 接続待機タイマー・自動再接続＆自然なペーシング
• フローティング HUD とポップアップで MCP（Desktop Commander など）や Gemini の接続・待機経過時間をリアルタイム表示。
• 設定時間（デフォルト5分）を超過すると自動停止し、未送信の下書きを保護しつつカスタム再接続メッセージ（デフォルト「继续，刚才mcp连接断开了」）を送信。ワンクリック「即時再開」ボタンも搭載。
• ランダム待機・分割入力・自然なホバークリック・60秒バースト抑制でレート制限を回避。

⚡ 4. インテリジェントな MCP 権限承認＆誤操作ガード
• 「常に許可（Always allow / 始终允许 / 常に許可）」ボタンを自動認識してスマートに承認。
• Material Web Components の Shadow DOM、`<slot>`、ドロップダウンメニューに対応。
• `/gems` や `/settings` 等のチャット外ページ、回答0件のホーム画面、2つ目のブラウザ復元タブの古いチップによる誤クリックを防止。
• 厳格なブラックリスト機能：拒否・キャンセル・削除などのボタンは絶対に誤クリックしません。

🎨 5. Notion 風ミニマル UI＆左ボタン押下ドラッグ HUD
• ライトペーパー / ダークチャコールを基調としたフラットな配色、1px ボーダー、低彩度セマンティックカラーを採用し、ログ消去・探索更新ツールバーや `innerHTML` 不使用の厳格な CSP 準拠を備えています。
• 左クリックでヘッダーを押下したままの時だけ移動（ホバーしただけでは追従しません）。4px 閾値後のポインターキャプチャにより折りたたみ・テーマ・言語ボタンが確実に反応し、座標保存や位置リセットにも対応。

🌗 6. 4言語切替 + ライト/ダークテーマ対応
• 簡体字中国語 / 繁体字中国語 / English / 日本語 をワンクリック切替（通知・キーワード対応）。
• ライトペーパーとダークチャコールのテーマを HUD とポップアップ間でリアルタイム同期。

🔔 7. タイムアウト＆回路遮断デスクトップ通知
• ツールの停止・生成停滞（デフォルト5分）または安全回路遮断が作動した際、ネイティブ通知とバッジでお知らせ。
• HUD とポップアップからワンクリックで通知のオン/オフを切替可能（オフ時は保留中の通知を即時解除）。通知クリックで該当の Gemini タブへ瞬時に移動します。

🤖 8. 自動「続行」および「Yes」チップの自動クリック
• 回答末尾の「↪ Yes」や「続行（Continue）」ボタンを自動的に認識してクリック。
• アンケートやナビゲーションは除外するため安全です。

🛡️ 9. 6層の回路遮断器＆境界防御（116 テスト検証済み）
• レイヤー 1：レートリミットや上限エラーを検知して瞬時に自動停止。
• レイヤー 2：1回のタスクあたりの連続クリック上限（デフォルト10回）。
• レイヤー 3：テキスト出力が安定するまで待機（1.8秒）＋ペーシング・クールダウン制御。
• レイヤー 4：1日あたりの最大クリック上限管理と Web Locks によるアトミック統計保存。
• レイヤー 5：「完了しました」などの終了文言を認識して無駄なクリックをスキップ。
• レイヤー 6：同一出力の繰り返しや進展がない場合に自動停止（ShadowRoot 循環防御・時計逆行保護を含む）。
