KenEasy Gemini MCP 自动助手

============================================================
2. 简短说明 (Summary - 最多 132 字符)
============================================================
自动点击 Gemini MCP 权限允许与继续按钮，支持四语言界面、黑白深浅模式、按住自由拖拽、桌面通知及 6 层防刷熔断。

============================================================
3. 详细说明 (Detailed Description - 直接复制下方全部内容)
============================================================
KenEasy Gemini MCP Auto Helper 是专为 Google Gemini 网页端（gemini.google.com）打造的 MCP 工具自动化辅助与连续对话增强扩展。

当你让 Gemini 调用本地或远程 MCP 服务器工具时，不再需要频繁守在屏幕前重复点击「始终允许」或「继续」按钮。v0.2 Beta 新增 4 语言实时切换、黑白深浅双模式、修复按住拖拽悬浮窗并加入非对话页与第 2 浏览器防误触护卫，内置 6 层防刷熔断保护，彻底解放双手！

🌟 核心功能亮点 (V0.2 Beta)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ 1. 智能 MCP 权限放行与多窗口防误触
• 智能识别并自动点击「始终允许 / Always allow / 常に許可」权限确认按钮。
• 完美穿透 Material Web Components Shadow DOM、<slot> 投影与下拉菜单。
• 严格过滤 `/gems`、`/extensions`、`/settings` 等非对话页及 0 回复首页，第 2 浏览器恢复旧会话时自动忽略陈旧追问芯片。
• 内置严格黑名单保护，绝不误触拒绝、删除、取消等破坏性按钮。

🖱️ 2. 按住自由拖拽悬浮窗 (Hold-to-Drag HUD) 🆕
• 仅在左键按住顶部标题栏时才跟随拖动，鼠标悬停靠近绝不粘连跟随！
• 4px 拖动消抖与延迟指针捕获，标题栏点击折叠、主题、语言切换按钮即时响应；Popup 支持「复位悬浮窗」。
• 视口边界碰撞保护与窗口缩放自动复位，坐标自动持久化保存。

🌗 3. 四语言切换 + 黑白深浅双模式 🆕
• 原生支持 简体中文 / 繁體中文 / English / 日本語，界面、桌面通知与识别词库全面适配。
• 深色夜间模式（🌙）与浅色白昼模式（☀️）随心切换，悬浮窗与 Popup 弹窗实时联动。

🔔 3. 卡死超时桌面通知 · 一键随心启闭 🆕
• 当 MCP 工具调用挂起或生成停滞超过设定阈值（默认 5 分钟）时，弹出系统级桌面通知，扩展图标呈现感叹号报警。
• 悬浮窗第 5 行药丸按键与弹窗面板均支持「一键开启 / 关闭」通知。
• 关闭通知时即时撤销背景所有悬挂的超时警报，清爽不打扰。
• 点击桌面通知直接唤醒并置顶对应的 Gemini 会话标签页。

🤖 4. 连续追问与「继续」智能点击
• 自动识别并点击 Gemini 答复末尾的确认类追问芯片（如「↪ Yes」）与「继续 / Continue」按钮。
• 严格过滤满意度调查、问卷、长篇引导提示与侧边栏历史记录，避免误点击。

🛡️ 5. 工业级 6 层防刷额度熔断保护 (Circuit Breaker)
为防止 AI 死循环或意外消耗过量 Token / 配额，内置全方位防护：
• Layer 1 (报错即停)：出现「配额超限」、「出了点问题」时 0 秒瞬时熔断。
• Layer 2 (单任务上限)：单次会话继续次数达到上限（默认 10 次）自动暂停。
• Layer 3 (输出停稳守卫)：必须等待文本流式输出彻底停稳（默认 1.8 秒）并经历冷却防抖（4 秒）。
• Layer 4 (跨天循环保护)：支持每日继续总上限，跨天自动复位。
• Layer 5 (完工语义识别)：识别「已全部完成」等结束语，跳过不必要的继续点击。
• Layer 6 (停滞与重复熔断)：比较前后回答 Hash，文本 100% 重复或无新进展即刻熔断。

💻 6. 后台切屏静默运行
• 支持在浏览器最小化或切换到其他窗口时平稳运行，通过长连接心跳与防丢弃机制，防止 Chrome 休眠 Gemini 标签页。

📖 使用指南
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 安装本扩展后，打开或刷新 Google Gemini 网页端（https://gemini.google.com/）。
2. 页面右侧即会呈现半透明的悬浮控制窗，可随时拖动至你喜欢的位置。
3. 点击浏览器右上角扩展图标可打开完整设置面板，自定义冷却时间、熔断上限与自定义匹配词。
