KenEasy Gemini MCP 自動助手

============================================================
2. 簡短說明 (Summary - 最多 132 字元)
============================================================
自動點擊 Gemini MCP 權限允許與繼續按鈕，支援四語言介面、黑白深淺模式、按住自由拖拽、桌面通知及 6 層防刷熔斷。

============================================================
3. 詳細說明 (Detailed Description - 直接複製下方全部內容)
============================================================
KenEasy Gemini MCP Auto Helper 是專為 Google Gemini 網頁端（gemini.google.com）打造的 MCP 工具自動化放行與連續對話增強擴充功能。

當你讓 Gemini 調用本地或遠端 MCP 伺服器工具時，不再需要頻繁守在螢幕前手動點擊「始終允許」或「繼續」按鈕。v0.3 Beta 新增 4 語言即時切換、黑白深淺雙模式、修復按住拖拽懸浮窗並加入非對話頁與第 2 瀏覽器防誤觸護衛，內建 6 層防刷熔斷保護，徹底解放雙手！

🌟 核心功能亮點 (V0.3 Beta)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ 1. 智慧 MCP 權限放行與多視窗防誤觸
• 智慧識別並自動點擊「始終允許 / Always allow / 常に許可」權限確認按鈕。
• 完美穿透 Material Web Components Shadow DOM、<slot> 投影與下拉選單。
• 嚴格過濾 `/gems`、`/extensions`、`/settings` 等非對話頁面及 0 回覆首頁，第 2 瀏覽器恢復舊會話時自動忽略陳舊追問晶片。
• 內建嚴格黑名單保護，絕不誤觸拒絕、刪除、取消等破壞性按鈕。

🖱️ 2. 按住自由拖拽懸浮窗 (Hold-to-Drag HUD) 🆕
• 僅在左鍵按住頂部標題列時才跟隨拖動，滑鼠懸停靠近絕不黏連跟隨！
• 4px 拖動消抖與延遲指標捕獲，標題列點擊折疊、主題、語言切換按鍵即時響應；Popup 支援「復位懸浮窗」。
• 視窗邊界防溢出保護與縮放自動復位，座標自動持久化儲存。

🌗 3. 四語言切換 + 黑白深淺雙模式 🆕
• 原生支援 简体中文 / 繁體中文 / English / 日本語，介面、桌面通知與識別詞庫全面適配。
• 深色夜間模式（🌙）與淺色白晝模式（☀️）隨心切換，懸浮窗與 Popup 彈窗即時聯動。

🔔 3. 卡死超時桌面通知 · 一鍵隨心啟閉 🆕
• 當 MCP 工具調用掛起或生成停滯超過設定閾值（預設 5 分鐘）時，主動彈出系統級桌面通知，擴充功能圖示呈現感嘆號報警。
• 懸浮窗第 5 行藥丸按鍵與彈窗面板均支援「一鍵開啟 / 關閉」通知。
• 關閉通知時即時撤銷背景所有懸掛的超時警報，清爽不打擾。
• 點擊桌面通知直接喚醒並置頂對應的 Gemini 對話分頁。

🤖 4. 連續追問與「繼續」智慧點擊
• 自動識別並點擊 Gemini 答覆末尾的確認類追問晶片（如「↪ Yes」）與「繼續 / Continue」按鈕。
• 嚴格過濾滿意度調查、問卷、長篇引導提示與側邊欄歷史紀錄，避免誤點擊。

🛡️ 5. 工業級 6 層防刷額度熔斷保護 (Circuit Breaker)
為防止 AI 陷入死迴圈或意外消耗過量 Token / 配額，內建全方位防護：
• Layer 1 (報錯即停)：出現「達到上限」、「配額超限」、「出了點問題」時 0 秒瞬時熔斷。
• Layer 2 (單任務上限)：單次會話繼續次數達到上限（預設 10 次）自動暫停。
• Layer 3 (輸出停穩守衛)：必須等待文字串流輸出徹底停穩（預設 1.8 秒）並經歷冷卻防抖（4 秒）。
• Layer 4 (跨天循環保護)：支援每日繼續總上限，跨天自動復位。
• Layer 5 (完工語義識別)：識別「已全部完成」等結束語，跳過不必要的繼續點擊。
• Layer 6 (停滯與重複熔斷)：比較前後回答 Hash，文本 100% 重複或無新進展即刻熔斷。

💻 6. 背景切屏靜默運作
• 支援在瀏覽器最小化或切換到其他視窗時平穩運行，透過長連線心跳與防休眠機制，防止 Chrome 休眠 Gemini 分頁。
